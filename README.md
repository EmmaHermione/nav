# 极简现代毛玻璃个人导航 (Glassmorphism Bento Navigation)

> 从 `https://nav.778080.xyz/` 全新重构升级的现代毛玻璃 Bento 风格个人导航工作台。

---

## ✨ 核心特性

- 💎 **毛玻璃 Bento 视觉风格**：采用高质量半透明磨砂玻璃卡片（`backdrop-blur`）、微光边框、柔和环境光晕与大圆角设计，支持深邃暗色与清新明亮主题。
- 📦 **91 个书签全量迁移**：原站 9 大分类及 91 个书签全部无损提取，并优化整理为结构更严谨的 8 大公开板块 + 1 个私密加密保险库。
- 🔒 **金融级 AES-256-GCM 密码学加密分类（防 F12 审查）**：
  - 私密分类书签在数据文件中**仅以密文形式存储**，源码及 `links.json` 中绝对不存在任何明文网址或标题；
  - 采用 PBKDF2（100,000 次加盐迭代）与原生 `Web Crypto API` AES-256-GCM 进行端到端解密；
  - 只有在输入正确密码时才动态解码渲染到内存，若密码错误直接在数学层面抛出认证失败，彻底免疫 F12 审查、控制台抓包或断点窥探。
  - **默认体验解锁密码**：`nav778080`
- 💬 **灵动一言（Hitokoto）组件**：顶部实时加载一言 API 语录，支持离线优雅降级与一键平滑旋转换一换。
- 🔍 **多引擎聚合 + 即时本地模糊搜索**：
  - 支持快捷切换 Google、百度、Bing、GitHub、Bilibili 搜索引擎；
  - 输入关键词秒级过滤全部 91+ 个书签卡片，高亮匹配结果，空分类自动隐藏；
  - 快捷键支持：全局按下 `/` 或 `Cmd/Ctrl+K` 瞬间聚焦搜索框，按 `Escape` 快速清空。
- 📋 **实用辅助**：卡片一键复制网址（带 Toast 弹窗反馈）、域名标签、图标加载失败自动优雅降级为文字彩色渐变徽标。
- 🚀 **零构建开箱即用 (Zero-build)**：纯静态工程，无需 Node.js、无需任何打包构建流程，双击即可本地运行，或直接上传至 Cloudflare Pages、Vercel、GitHub Pages、Nginx。

## 🛠️ 如何配置与维护

### 1. 修改普通书签与分类
打开 `links.json`，在 `categories` 数组中直接增加或修改分类与书签对象即可：
```json
{
  "title": "网站名称",
  "url": "https://example.com",
  "description": "网站简介描述",
  "icon": "图标URL（若留空则自动生成首字母渐变徽标）"
}
```

### 2. 更新或更换私密分类与密码
您有两种简单方式来加密并更新您的私密分类：

#### 方式 A：直接在网页中使用【加密工具箱】（推荐）
1. 点击网页左下角的 **「加密工具箱」** 按钮；
2. 输入您自设的解锁密码，在下方填入私密书签的 JSON 数组；
3. 点击 **「一键生成加密密文」**；
4. 点击「复制结果」，将生成的 `"crypto": { ... }` 整段直接粘贴替换掉 `links.json` 中的 `"crypto": { ... }` 即可。

#### 方式 B：通过命令行运行加密脚本
在终端中执行：
```bash
node encrypt_tool.js "您的自定义密码"
```
终端将自动打印出带有 `"crypto": { ... }` 的完整节点，直接复制整段替换至 `links.json` 即可。

## 🌐 部署指南

因为本项目是零构建依赖的纯静态项目：

- **Cloudflare Pages / Vercel**：直接连接 GitHub 仓库，Build Command 留空，Output Directory 填 `.` 或根目录即可秒级部署。
- **GitHub Pages**：进入仓库 Settings -> Pages -> Source 选择 `main` 分支根目录保存即可。
- **Nginx / 虚拟主机**：将目录内的全部文件直接上传至网站根目录即可。
